# 多面体の面と3ビット演算

更新: 2026-09-07

対象は CHROMALUM の八状態 `A={0,1}³` で、ビット順は `[G,R,B]` とする。
`K=000, B=001, R=010, M=011, G=100, C=101, Y=110, W=111`。
本稿は既知のブール代数・有限幾何・符号理論を、現在の頂点ラベルと面の組合せに適用した導出を記録する。

Theory 本文には立方体の面、テトラの面、Hamming の検査面、八面体とFano・XORの短い対応説明を置く。八面体の八行の混色表は本稿に残し、混色の操作は専用のGRB・YCMグラフで扱う。
テトラは距離2の分解と補色交換を本線とし、本文には三頂点のXORで残る頂点を復元できることだけを短く残す。面選択図・計算表は本文から外し、多数決・面重心・双対性の導出は本稿に残す。14組のアフィン平面と拡張 Hamming 符号も本稿で扱う。

## 立方体の面: 四点のXORと束区間

一つの面は一つの座標を固定し、残る二座標の全組合せを取る。
四頂点を `a,b,c,d` とすれば各座標の1の個数は0、2、4のいずれかなので、

```text
a⊕b⊕c⊕d=000
d=a⊕b⊕c
```

である。例えば `G⊕C⊕Y=100⊕101⊕110=111=W`。
同じ面の二点の AND・OR は固定座標を保存するため、面内に留まる。
面は包含順序の区間 `[l,u]` で、`l=AND(face)`, `u=OR(face)`、自由な座標は二つである。
二要素鎖二つの直積であるブール束 `B₂` と同型だが、全体の補色は反対の面へ移る。
面内の相対補元は `x↦x⊕(u⊕l)` である。

各対角線の両端の AND は `l`、OR は `u`、XOR は `u⊕l` になる。
valuation により対角線の両端の順位和はどちらも `L(l)+L(u)` である。

## 距離2: 二つのカラーテトラと反転

偶奇 `π(c)=g⊕r⊕b` が同じ異なる二状態では、差分は非零の偶数重みなので距離2に限られる。したがって距離2グラフは、互いに素な二つの `K4(T0)` と `K4(T1)` であり、標準立方体配置では二つの正四面体になる。

立方体の8頂点から作る正四面体では、6組の平方ユークリッド距離、すなわちHamming距離が等しい。距離1の立方体グラフは三角形を含まず、距離3では各頂点の相手が一つだけなので、4頂点の等距離集合は距離2に限られる。ある頂点と同じ偶奇の残る三点を取るしかないため、正四面体はT0とT1の二つだけである。

反転マスク `m` に対して `π(c⊕m)=π(c)⊕π(m)` となる。M=011、C=101、Y=110の二チャンネル反転は各テトラを保ち、G=100、R=010、B=001の一チャンネル反転とW=111の全ビット反転は二つを交換する。特に各頂点を補色にすると `¬T0=T1`、`¬T1=T0`。

同じ立方体配置での二四面体の複合をカラースターと呼ぶ。Theory では距離2と反転の構造を主題とし、以下の面演算は補足として扱う。

## テトラの面: XOR復元と多数決

`T0={K,M,C,Y}` と `T1={B,R,G,W}` の各四頂点では、どの座標にも1が二つある。
面の三頂点を `a,b,c`、残る頂点を `d` とすると、

```text
a⊕b⊕c=d
maj(a,b,c)=(a∧b)∨(b∧c)∨(c∧a)=¬d
```

となる。多数決は AND・OR から作る派生演算である。
頂点 `d` を除いた面で座標 `i` の1の個数は `2−d_i`。
それが2以上になるのは `d_i=0` の場合だけなので、多数決は `¬d` を返す。

| テトラ | 面    | XOR / 残る頂点 | 多数決 / 補色頂点 |
| ------ | ----- | -------------- | ----------------- |
| T0     | K,M,C | Y              | B                 |
| T0     | K,M,Y | C              | R                 |
| T0     | K,C,Y | M              | G                 |
| T0     | M,C,Y | K              | W                 |
| T1     | B,R,G | W              | K                 |
| T1     | B,R,W | G              | M                 |
| T1     | B,G,W | R              | C                 |
| T1     | R,G,W | B              | Y                 |

全てのテトラ面で三点の OR は W、AND は K となる。
三辺の差分マスク `{a⊕b,b⊕c,c⊕a}` は必ず `{M,C,Y}` で、その XOR は000である。
これは頂点の三点組が Fano 線であるという主張とは異なる。
頂点の XOR が000になるテトラ面は、欠けた頂点がKであるCMY面だけである。

### 正四面体の双対対応

立方体の中心を原点とし、二値頂点の中心化した三次元位置を `p_x` とする。
一様な拡大縮小や剛体回転を加えても次の関係は保たれる。

```text
p_a+p_b+p_c+p_d=0
p_¬d=−p_d
g_F=(p_a+p_b+p_c)/3=−p_d/3=p_¬d/3
```

面の重心 `g_F` は、もう一方のテトラの頂点 `¬d` に向かう半径の三分の一にある。
正四面体ではこの半径は面に垂直であり、中心から3倍拡大した面重心が相手の頂点になる。
多数決はこの面–頂点の双対対応の色ラベルを計算する。
重心自体は色状態ではなく、表示幾何上の点である。

各テトラの順位和は `2(4+2+1)=14` なので、面の三頂点の順位和は `14−L(d)`。
より一般に、任意の三入力について各座標の1の個数を偶奇と多数決に分けると、

```text
L(a)+L(b)+L(c)=L(a⊕b⊕c)+2L(maj(a,b,c))
```

が成り立つ。これは整数の和の恒等式であり、XORを通常の加算や混色と同一視するものではない。

## 八面体: XOR・補色・Fano線

### 一辺から二つの三角形を復元する

六有彩色を `C={R,G,B,C,M,Y}` とする。異なる `a,b∈C` について、`a⊕b∈C` と `a,b` が非補色であることは同値である。等しい色のXORはK、補色のXORはWなので、有彩色の結果を返す入力組をすべて結ぶと `K6` から三補色対を除いた八面体グラフになる。

辺 `a–b` の両側の三角形の第三頂点は、

```text
c0 = a⊕b
c1 = ¬(a⊕b)
a⊕b⊕c0 = 000
a⊕b⊕c1 = 111
```

である。`c0,c1` はともに有彩色で、`a,¬a,b,¬b` のどれでもない。したがって、三補色対のうち残る一対そのものであり、二つの三角形をそれぞれ完成させる。

XORが000の四面 `{R,G,Y}`, `{G,B,C}`, `{B,R,M}`, `{C,M,Y}` は、各辺をちょうど一回ずつ含む。どの面でも二頂点のXORが残る頂点になるため、有彩色にとどまる全12組のXOR関係をこの四面で表せる。各辺のもう一方の面では、第三頂点はXORの補色になる。

Theory の辺選択はこの規則を使う。初期状態ではR–Gの辺を選び、XORと補色側の二つの結果を常時表示する。同じ辺の再選択や本文背景のクリックでも選択済みの結果を保ち、別の辺を選ぶと更新する。XORの第三頂点と面を青、補色側を黄、共通の辺を白で示し、二色の計算と三点XORを区別する。「有彩六色の八面体」では正八面体だけを表示する。上をR、下をCとする剛体回転を用い、他の四頂点は上段M/Y・下段B/Gへ配置する。ダイスとの双対は本文の補足として扱い、頂点の位置ビットや面・頂点の切替を設けない。

### 混色との対応（研究補足）

三補色対から一色ずつ選ぶ八つの三点組が面になる。
以下は面の頂点ラベルについての関係であり、標準RGB座標の非正則八面体と表示用の正則八面体で共通する。
面ラベルの3ビットは、各補色対で原色側を選んだかを記録する位置ラベルである。以下の表は、既存の混色関係とこのラベルとの対応を調べる研究上の補足として扱う。

| 面    | 面ラベル | 混色関係 | 三点XOR | 多数決 |
| ----- | -------- | -------- | ------- | ------ |
| R,G,B | W        | R∨G∨B=W  | W       | K      |
| R,G,Y | Y        | R∨G=Y    | K       | Y      |
| G,B,C | C        | G∨B=C    | K       | C      |
| B,R,M | M        | B∨R=M    | K       | M      |
| C,M,Y | K        | C∧M∧Y=K  | K       | W      |
| C,M,B | B        | C∧M=B    | W       | B      |
| M,Y,R | R        | M∧Y=R    | W       | R      |
| Y,C,G | G        | Y∧C=G    | W       | G      |

原色が二つ以上なら三点の OR、CMY が二つ以上なら三点の AND が面ラベルに対応する色を返す。
混合面は二入力とその結果からなるので、結果を第三入力として加えても冪等性によって答えは変わらない。
この八関係は、専用のGRB・YCM混色グラフで示す六つの二色関係と二つの三色関係に一致する。
OR と AND は面の種類に応じて使い分けており、全八面に一つの混色演算を適用する法則ではない。Theory 本文ではこの表を繰り返さず、次のFano・XOR対応を短く説明する。

XOR がKになる四面は Fano の四本の線と同じ三点組である。
三点を全て補色にすると、XOR は `7⊕7⊕7=7` だけ変わるため、反対側の四面のXORはWになる。
原色側の軸選択をビットで表した面ラベルを `s` とすると、三点のXORは `wt(s)` が偶数ならK、奇数ならWである。
したがって面ラベルの T0/T1 分割が、面上三点のXORの白黒分割に対応する。
多数決は六つの混合面では面ラベルに一致するが、RGB面とCMY面ではK/Wを入れ替えるので、全八面の着色則には使わない。

頂点集合としては、六つの混合面は立方体の各面からKまたはWを取り除いた三点組である。
残るRGB面とCMY面は、それぞれT1とT0の面である。

### カラースターの共通部分

立方体の各面にはT0とT1の辺が対角線として一本ずつ通り、どちらの中点も面中心になる。よって、T0の六辺の中点、T1の六辺の中点、立方体の六面の中心は同じ六点であり、表示中の正八面体の頂点になる。

中心化した座標を `p(c)=2ι(c)−(1,1,1)` とする。二つのテトラの四面の不等式を合わせると、全八符号の `±x±y±z≤1`、すなわち `|x|+|y|+|z|≤1` となる。したがって、

```text
conv(p(T0)) ∩ conv(p(T1)) = conv{±e_G, ±e_R, ±e_B}
```

であり、二つのテトラが囲む領域の共通部分も同じ正八面体になる。これはカラースターの中心の立体である。中点と共通部分はユークリッド表示上の点・領域として扱い、離散的な色集合は `T0∩T1=∅` のままである。

## Hammingの検査組を立方体の面として読む

符号語の位置を非零の色ラベル1〜7で表すと、既存の三検査組は、

```text
B / P1: {1,3,5,7} = {B,M,C,W} = B座標が1の面
R / P2: {2,3,6,7} = {R,M,Y,W} = R座標が1の面
G / P4: {4,5,6,7} = {G,C,Y,W} = G座標が1の面
```

になる。面の頂点集合は検査対象の位置を定める。
検査値はその四位置に置かれた符号ビットのXORであり、色番号のXORとは異なる。
Kの位置は元の七ビット符号語には存在しない。

## 発展: 14組の四点集合と拡張Hamming符号

異なる四点のXORが000になる集合は14組ある。
非零ベクトル `n` と `ε∈{0,1}` に対して、二元体上の内積で

```text
P(n,ε)={x∈F₂³ : n·x=ε}
```

と書いた7方向×2組のアフィン平面である。
三つの相異なる点 `a,b,c` に対して `a⊕b` と `a⊕c` は独立なので、
`{a,b,c,a⊕b⊕c}` はそれらが張る二次元アフィン部分空間になる。
第四点は一意で、`C(8,3)/4=56/4=14` となる。

| 法線nの重み | 方向数 | 四点集合数 | 通常のRGB座標での形                |
| ----------- | ------ | ---------- | ---------------------------------- |
| 1           | 3      | 6          | 立方体の六つの正方形面             |
| 2           | 3      | 6          | 二本の補色対角線を含む六つの長方形 |
| 3           | 1      | 2          | T0とT1の正四面体                   |

ここでのアフィン平面は二元体上の概念である。
通常の三次元空間で四点が同一平面にあることを要求せず、最後の二組は立体の四面体になる。
Kを含む七組からKを除くと、Fano平面の七本の線が得られる。

八色を位置として各集合の指示ベクトル `w=(w_0,…,w_7)` を作る。
14個の重み4の列に、空集合の `00000000` と全集合の `11111111` を加えると16列になる。
これらは全てのアフィン関数 `f(x)=α⊕n·x` の値列であり、次元4の線形符号 `RM(1,3)` をなす。
非定数のアフィン関数は四位置で1になるため非零重みは4または8、最小距離は4である。
これが拡張 Hamming `[8,4,4]` 符号である。

Kに対応する位置 `w_0` を除くと、各列は

```text
H wᵀ = XOR { i∈{1,…,7} : w_i=1 } = 000
```

を満たす。重み4の集合では四点のXORが000であり、Kを取り除いてもXORは変わらない。
全集合の列でも1〜7のXORは000である。削除前の最小距離が4なので、この一位置の削除は16列を互いに区別したまま保つ。
従って得られる16列は、rank 3のHの核である既存の Hamming `[7,4,3]` 符号と一致する。

この八ビット列は八色の選択状態であり、一色を表すGRB三ビットとは別の対象である。
